# AI Builder User Guide

## Introduction

The AI Builder is a powerful tool that allows you to create sophisticated AI-driven instructions and workflows. Whether you're building AI Agents, Blueprints, or AI Sessions, the AI Builder provides a guided process to help you create effective instructions using predefined templates or your own custom content and files.

The AI Builder transforms your high-level vision into precise AI instructions through an intuitive, step-by-step process that requires no technical expertise.

AI Builder can be accessed through:

![AI Builder Welcome Screen](https://help.sairis.ai/assets/ai-builder-welcome.png) *(Replace with actual screenshot)*

• The main navigation menu under "AI Management"

## AI Builder Interface Overview

The AI Builder consists of several key components:

1. **Welcome Screen**: Introduces the AI Builder with feature overview and mode selection
2. **Step Navigation**: Left sidebar showing your progress through the builder process

5. **Action Buttons**: Save, Next, Previous, and other workflow controls

## AI Builder Modes

The AI Builder offers two distinct modes to match your experience level and requirements:

### Simple Mode (3 Steps)

Perfect for users who want to create AI instructions quickly without complex configurations:

**Step Flow**: Settings → AI Instructions → Output

- **Builder Settings**: Configure basic AI Builder properties and associate with Blueprints
- **AI Instructions**: Single guided interview process to create comprehensive instructions
- **Output**: Review and publish your AI instructions to a Blueprint

**Best For**:
- Quick AI instruction creation
- First-time users
- Simple use cases with standard requirements

### Advanced Mode (6 Steps)

Provides complete control and customization for sophisticated AI applications:

**Step Flow**: Settings → Role → Tone & Style → My Instructions → Output Format → AI Instructions

- **Builder Settings**: Configure AI Builder properties and Blueprint associations
- **AI Role**: Define what role the AI should adopt with customizable personas
- **Tone & Style**: Set communication style with ready-to-use presets and style guides
- **My Instructions**: Create detailed processing instructions using advanced workflows
- **Output Format**: Define how the AI presents results (reports, charts, summaries, custom formats)
- **AI Instructions**: Review and refine the complete instruction set

**Best For**:
- Complex AI applications
- Advanced users who need fine-grained control
- Multi-step workflows with specific requirements
- Professional or enterprise use cases

## Getting Started Options

When you first open the AI Builder, you'll choose how to begin:

![Getting Started Options](https://help.sairis.ai/assets/ai-builder-start.png) *(Replace with actual screenshot)*

### Option 1: New AI Instructions
Create a completely new set of AI instructions from scratch:
1. Click "New AI Instructions"
2. Choose your preferred mode (Simple or Advanced)
3. Follow the guided steps to build your instructions

### Option 2: Open/Copy AI Builder
Work with an existing AI Builder:
1. Click "Open/Copy AI Builder"
2. Choose "Open" to edit an existing AI Builder or "Copy" to create a new one based on existing instructions
3. Select the AI Builder from the dropdown list
4. Continue with your selected mode

### Option 3: Open/Copy Blueprint
Start from an existing Blueprint:
1. Click "Open/Copy Blueprint"
2. Choose "Open" to edit the AI Builder associated with a Blueprint or "Copy" to create a new AI Builder based on the Blueprint
3. Select the Blueprint from the dropdown list
4. The system will load the associated AI Builder for editing

## Builder Settings Configuration

The first step in both modes involves configuring your AI Builder settings:

![Builder Settings](https://help.sairis.ai/assets/ai-builder-settings.png) *(Replace with actual screenshot)*

### Required Settings

**AI Builder Name**:
- Enter a descriptive name for your AI Builder
- This name will be used for identification and organization
- Choose something meaningful that describes the AI's purpose

**Description**:
- Provide a detailed explanation of what this AI Builder does
- Include the intended use case and expected outcomes
- This helps other users understand the AI's capabilities

### Optional Settings

**Associated Blueprint**:
- Link your AI Builder to an existing Blueprint for deployment
- Click "Change" to browse available Blueprints
- You can associate with a Blueprint later if preferred

**Mode Selection**:
- Choose between Simple Mode (3 steps) or Advanced Mode (6 steps)
- This determines the complexity of the configuration process
- You can see detailed descriptions by clicking "Show Details"

## Advanced Mode Steps

### Step 1: AI Role Definition

Define what role your AI should adopt and how it should behave:

![AI Role Configuration](https://help.sairis.ai/assets/ai-builder-role.png) *(Replace with actual screenshot)*

**Role Categories**:
- **Analyst**: Data analysis and research-focused roles
- **Creative**: Writing, design, and creative content roles
- **Technical**: Programming, engineering, and technical roles
- **Business**: Management, strategy, and business-focused roles
- **Support**: Customer service and help desk roles
- **Custom**: Create your own unique role definition

**Role Configuration Options**:

1. **Use Predefined Role Templates**:
   - Browse curated role templates organized by category
   - Each template includes pre-written role descriptions and behavioral guidelines
   - Simply select and customize as needed

2. **Create Custom Role**:
   - Write your own role definition from scratch
   - Define the AI's expertise, personality, and approach
   - Include specific behavioral guidelines and restrictions

**Best Practices for AI Roles**:
- Be specific about the AI's expertise and limitations
- Define the target audience the AI should address
- Include examples of ideal interactions when possible
- Specify any industry-specific knowledge requirements

### Step 2: Tone & Style Configuration

Control how your AI communicates and presents information:

![Tone & Style Settings](https://help.sairis.ai/assets/ai-builder-tone.png) *(Replace with actual screenshot)*

**Communication Styles**:
- **Professional**: Formal, business-appropriate language
- **Conversational**: Friendly, approachable tone
- **Academic**: Scholarly, research-oriented communication
- **Technical**: Precise, specification-focused language
- **Creative**: Engaging, imaginative expression
- **Custom**: Define your own unique style

**Style Configuration Options**:

1. **Predefined Style Templates**:
   - Ready-to-use tone presets for common scenarios
   - Each template includes writing guidelines and examples
   - Organized by industry and use case

2. **Upload Style Examples**:
   - Upload documents that demonstrate your desired communication style
   - The AI will analyze and learn from your examples
   - Supports multiple file formats (PDF, DOC, TXT)

3. **Custom Style Definition**:
   - Write detailed style guidelines
   - Include specific vocabulary preferences
   - Define formatting and structure requirements

### Step 3: My Instructions (Workflow Definition)

Create detailed instructions for how your AI should process information:

![My Instructions](https://help.sairis.ai/assets/ai-builder-instructions.png) *(Replace with actual screenshot)*

**Instruction Types**:
- **Analysis Instructions**: How to analyze data and information
- **Processing Steps**: Sequential steps for handling requests
- **Decision Trees**: Conditional logic for different scenarios
- **Quality Checks**: Validation and verification procedures
- **Output Guidelines**: How to format and present results

**Workflow Components**:

1. **Predefined Workflows**:
   - Common processing patterns for typical use cases
   - Tested and optimized instruction sets
   - Easy to customize and extend

2. **Custom Instructions**:
   - Write your own processing instructions
   - Define step-by-step procedures
   - Include conditional logic and decision points

3. **File-Based Instructions**:
   - Upload documents containing detailed procedures
   - Reference external documentation and standards
   - Maintain consistency with existing processes

### Step 4: Output Format Configuration

Define how your AI presents results and information:

![Output Format](https://help.sairis.ai/assets/ai-builder-output.png) *(Replace with actual screenshot)*

**Output Types**:
- **Reports**: Structured documents with sections and summaries
- **Charts & Visualizations**: Data represented graphically
- **Summaries**: Concise overviews of key information
- **Lists**: Organized bullet points and numbered items
- **Tables**: Structured data presentation
- **Custom Formats**: Your own unique output specifications

**Format Options**:

1. **Predefined Format Templates**:
   - Professional report formats
   - Standard business document structures
   - Industry-specific output patterns

2. **Upload Format Examples**:
   - Provide examples of desired output formats
   - The AI will learn your preferred structure and style
   - Supports various document types

3. **Custom Format Definition**:
   - Specify exact formatting requirements
   - Define sections, headers, and structure
   - Include styling and presentation guidelines

**Advanced Output Features**:
- **Interactive Elements**: Collapsible sections, expandable details
- **Media Integration**: Images, videos, and embedded content
- **Next Steps**: Actionable recommendations and follow-up items
- **Data Visualization**: Charts, graphs, and infographics

### Step 5: AI Instructions Review

Review and finalize your complete AI instruction set:

![AI Instructions Review](https://help.sairis.ai/assets/ai-builder-final.png) *(Replace with actual screenshot)*

This final step combines all your previous configurations into a comprehensive instruction set that includes:

- **Combined Instructions**: All steps merged into coherent AI instructions
- **Optimization Options**: AI-powered suggestions to improve instructions
- **Testing Interface**: Built-in chat to test your AI instructions
- **Export Options**: Save instructions for use in Blueprints or other applications

## Blueprint Integration

### Creating New Blueprints
From your AI Builder, you can create new Blueprints:

1. Complete your AI instruction configuration
2. Click "Create Blueprint" in the final step
3. Provide Blueprint name and description
4. Configure Blueprint-specific settings (AI model, content sources, etc.)
5. Save and deploy your Blueprint

### Updating Existing Blueprints
Link your AI Builder to existing Blueprints:

1. In Builder Settings, click "Change" next to Associated Blueprint
2. Select from available Blueprints
3. Your AI instructions will be applied to the selected Blueprint
4. Save changes to update the Blueprint

### Blueprint Settings Integration
When associated with a Blueprint, your AI Builder can access:
- Knowledge Base content
- Web search capabilities
- Live news integration
- Specific web pages
- Content filtering and scoring

## Troubleshooting

### Common Issues and Solutions

**Issue: Cannot save AI Builder**
- Verify you have edit permissions
- Ensure all required fields are completed
- Check for validation errors in the interface
- Try refreshing and re-entering changes

**Issue: AI instructions not working as expected**
- Review role definition for clarity and specificity
- Check tone and style settings match desired output
- Verify processing instructions are complete and logical
- Test with simpler queries first, then increase complexity

**Issue: Output format not matching expectations**
- Review format examples and templates used
- Check if advanced features are properly enabled
- Verify output configuration matches intended structure
- Test with various input types to ensure consistency

**Issue: Unable to associate with Blueprint**
- Confirm you have access to the target Blueprint
- Check if Blueprint is locked or has restricted access
- Verify Blueprint and AI Builder are compatible
- Contact administrator if permissions seem incorrect

**Issue: Performance problems during testing**
- Complex instructions may require more processing time
- Simplify instructions if responses are too slow
- Check if external content sources are causing delays
- Consider breaking complex workflows into smaller steps

## Best Practices

### Instruction Writing
- **Be Specific**: Vague instructions lead to inconsistent results
- **Use Examples**: Provide concrete examples of desired behavior
- **Test Iteratively**: Build and test incrementally rather than all at once
- **Consider Edge Cases**: Plan for unusual or unexpected inputs

### Role Definition
- **Define Expertise Boundaries**: Clearly state what the AI should and shouldn't know
- **Specify Audience**: Tailor the role to your target users
- **Include Personality**: Give the AI character that matches your brand
- **Set Limitations**: Be explicit about what the AI cannot or should not do

### Output Formatting
- **Consistency**: Ensure outputs follow the same structure across different inputs
- **Readability**: Design outputs that are easy to scan and understand
- **Actionability**: Include next steps and actionable recommendations
- **Accessibility**: Consider users with different needs and abilities

### Testing and Validation
- **Comprehensive Testing**: Test various scenarios and input types
- **User Acceptance**: Have target users test and provide feedback
- **Performance Monitoring**: Track response times and user satisfaction
- **Continuous Improvement**: Regularly update based on usage patterns

### Collaboration
- **Documentation**: Maintain clear documentation of AI Builder purposes and changes
- **Version Control**: Keep track of significant changes and improvements
- **Knowledge Sharing**: Share successful patterns and techniques with team members
- **Feedback Integration**: Incorporate user feedback into instruction improvements
