# Bans Management Guide

Bans allow you to block certain words from being asked. If a user submits a request and it matches any of the bans it will reject the request and let the user know.


## Bans Management Interface

![homepage](/images/bans-manage.png)


- Profanity by default is turned not allowed.  Use the toggle to allow
- Add banned words by entering in the text input
- Add additional by selecting 'Add Banned Word' button
